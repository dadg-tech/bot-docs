# Приложения для подключения

Подключение работает через бесплатное приложение на вашем устройстве. Бот сам подскажет, какой способ выбрать, и пришлёт готовую ссылку, файл или QR-код для импорта.

Удобнее установить приложение заранее — тогда после оплаты останется только импортировать доступ.

!!! tip "Какой способ выбрать"
    Если не уверены — начните с **AmneziaVPN**: это основной способ для повседневной работы. **Happ** держите как запасной вариант на случай, если основное подключение недоступно.

## AmneziaVPN

Основной способ подключения для телефона, ноутбука и планшета.

| Платформа              | Где скачать                                                                              |
| ---------------------- | --------------------------------------------------------------------------------------- |
| iPhone и iPad          | [App Store](https://apps.apple.com/app/amneziavpn/id1600529900)                          |
| Android                | [Google Play](https://play.google.com/store/apps/details?id=org.amnezia.vpn)            |
| Windows, macOS, Linux  | [amnezia.org/downloads](https://amnezia.org/downloads)                                   |

После установки откройте ссылку из бота или отсканируйте QR-код в приложении — доступ импортируется автоматически.

## Happ

Запасной способ подключения, когда основной недоступен.

| Платформа                   | Где скачать                                                                       |
| --------------------------- | -------------------------------------------------------------------------------- |
| iPhone и iPad               | [App Store](https://apps.apple.com/app/happ-proxy-utility/id6504287215)          |
| Android                     | [Google Play](https://play.google.com/store/apps/details?id=com.happproxy)       |
| Windows, macOS, Linux и др. | [happ.su](https://happ.su/)                                                       |

После установки используйте ссылку быстрого импорта `happ://import/...` из бота или отсканируйте QR-код.

!!! note "Доступность способов"
    Набор доступных способов подключения может меняться. Ориентируйтесь на то, что предлагает бот в момент добавления устройства.
