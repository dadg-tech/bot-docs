# Устройства

Устройство — это телефон, компьютер, планшет или другой клиент, который подключается через бота. Лимит устройств зависит от тарифа.

Перед подключением установите приложение — ссылки для всех платформ собраны на странице [Приложения](apps.md).

## Способы подключения

При добавлении устройства бот предложит выбрать способ и пришлёт готовые данные для импорта.

=== "AmneziaVPN"

    Основной способ для повседневной работы. Бот отправляет:

    - ссылку для быстрого импорта в приложение;
    - файл конфигурации;
    - QR-код;
    - данные для ручной настройки, если ссылка не открывается.

    Откройте ссылку или отсканируйте QR-код в приложении AmneziaVPN.

=== "Happ"

    Запасной способ, когда основное подключение недоступно. Бот отправляет:

    - ссылку подписки;
    - ссылку быстрого импорта `happ://import/...`;
    - QR-код для импорта.

    Если приложение установлено, используйте ссылку быстрого импорта. Если она не открывается, скопируйте ссылку подписки вручную.

## Лимит устройств

Лимит задаётся тарифом и общий для всех способов подключения.

!!! example "Пример"
    Если тариф разрешает 3 устройства, можно добавить 2 на AmneziaVPN и 1 на Happ — или любую другую комбинацию в пределах лимита.

## Добавление и удаление

Откройте «Управление устройствами» или отправьте:

```text
/devices
```

Здесь можно добавить, удалить, переименовать устройство и посмотреть список подключений.

!!! warning "Превышен лимит после смены тарифа"
    Если устройств стало больше, чем разрешено, бот попросит удалить лишние вручную или разрешить автоматическое удаление.

## Истечение подписки

Если подписка истекла, доступ останавливается.

Чтобы восстановить подключение:

1. Пополните баланс.
2. Дождитесь возобновления подписки.
