# Как пользоваться ботом

Короткий путь от запуска бота до защищённого подключения на вашем устройстве.

## Старт

Откройте Telegram-бота и отправьте команду:

```text
/start
```

Бот покажет состояние подписки, баланс и доступные действия. Регистрация происходит автоматически.

### Команды бота

| Команда     | Что делает              |
| ----------- | ----------------------- |
| `/start`    | Открыть главное меню     |
| `/help`     | Помощь и поддержка       |
| `/profile`  | Профиль и баланс         |
| `/tariffs`  | Тарифы и пополнение      |
| `/devices`  | Устройства               |
| `/cancel`   | Отменить текущий шаг     |

## Купить доступ

1. Нажмите «Выбрать тариф» или отправьте `/tariffs`.
2. Выберите тариф.
3. Выберите срок пополнения: **1, 3 или 6 месяцев**.
4. Оплатите счёт через Telegram Stars.

!!! success "После оплаты"
    Stars зачисляются на баланс. Когда приходит дата продления, бот сам списывает стоимость тарифа с баланса — подписка продлевается автоматически.

!!! note "Способ оплаты"
    Оплата проходит только через Telegram Stars, прямо в Telegram.

## Подключить устройство

После активации подписки нажмите «Добавить устройство» и введите имя — например, `iPhone`, `MacBook` или `Домашний ПК`.

Затем выберите способ подключения. Бот пришлёт ссылку, файл или QR-код для импорта:

=== "AmneziaVPN"

    Основной способ для повседневной работы. Бот отправляет:

    - ссылку для быстрого импорта в приложение;
    - файл конфигурации;
    - QR-код;
    - данные для ручной настройки, если ссылка не открывается.

=== "Happ"

    Запасной способ, когда основное подключение недоступно. Бот отправляет:

    - ссылку подписки;
    - ссылку быстрого импорта `happ://import/...`;
    - QR-код для импорта.

!!! tip "Установите приложение заранее"
    Ссылки для всех платформ — на странице [Приложения](apps.md). Тогда после оплаты останется только импортировать доступ.

## Управление устройствами

Откройте «Управление устройствами» или отправьте:

```text
/devices
```

В этом разделе можно:

- добавить устройство;
- удалить устройство;
- переименовать устройство;
- посмотреть список подключённых устройств.

!!! warning "Удаление требует подтверждения"
    Перед удалением бот всегда просит подтвердить действие.

## Лимит устройств

Лимит устройств зависит от тарифа и считается для всех подключений вместе.

!!! example "Пример"
    Если тариф разрешает 3 устройства, это может быть 2 на AmneziaVPN и 1 на Happ — или любая другая комбинация в пределах лимита.

Если после смены тарифа устройств стало больше, чем разрешено, бот попросит удалить лишние вручную или разрешить автоматическое удаление.

## Если подписка истекла

Когда на балансе недостаточно Stars для продления, подписка становится неактивной, а доступ останавливается. Бот сообщит причину.

Чтобы восстановить доступ:

1. Пополните баланс через «Выбрать тариф».
2. Дождитесь возобновления подписки.

!!! warning "Доступ не вернулся автоматически?"
    Откройте профиль через `/profile` или напишите в поддержку командой `/help`.
